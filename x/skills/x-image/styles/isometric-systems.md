# Isometric Systems

```yaml
id: isometric-systems
use-for: spatial process explanations, system architecture, pipelines, feedback mechanisms, and operational flows
background: pale cool gray #EEF1F3 with an uncluttered seamless ground plane
palette: matte graphite, warm white, brushed aluminum, and one semantic accent system
accent: burnt orange #D4633C for friction or failure; emerald #2E8B67 may appear only when an explicit remedy contrast is required, locked across a set
medium: restrained isometric 3D mechanism built from matte metal, rubber conveyors, chutes, gates, frames, and modular platforms
lighting: soft high three-quarter studio light with crisp readable planes and restrained shadows
composition: one self-contained spatial process machine seen from a high three-quarter isometric angle; use left-to-right flow or one closed loop with clear entry, transformation, and exit
text-rules: exact concise labels only on front-facing label plates; exact visible text is exhaustive; never distort labels into perspective or place them on moving parts
avoid: factory scenery, robots, decorative gears, smokestacks, pipes without meaning, gauges, dashboards, photoreal industrial grime, glossy sci-fi chrome, neon glow, watermark, fake interface chrome, multiple focal points
```

Every conveyor, gate, bridge, or return path must encode a real spatial process relationship. Use mechanical structure as explanation, not as factory decoration.

Keep label plates visually front-facing even when the mechanism is isometric. Leave them blank when no exact text is required.
