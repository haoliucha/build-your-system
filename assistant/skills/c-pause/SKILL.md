# 间隙记录

间隙日志的核心：在 30 秒内记录“刚完成 / 感受 / 下一步”，下一步必须具体可执行。

**用户提供的参数**

## 执行流程

1. 检查 `60-Memory/profile.md`；缺失时提示运行 `a-setup` 后停止。
2. 读取 GMT+8 当前时间，格式化为 `HH:MM`。
3. 有完整参数时直接提取三项；信息不足时询问缺失项。触发条件、情绪映射和写入格式见 capture-rules §6。
4. 写入当日日记的 `## 间隙日志`，新记录放在区块最前面；日记路径按
   `00-Inbox/{YYYY-MM-DD}.md`，缺失时查 `00-Inbox/{Y}/{Y-M}/{日期}.md`。
5. 返回时间、保存结果和具体下一步，不把记录复制到 `capture.md`。

## 快速模式

用户提供“刚完成”和“下一步”时可跳过提问。无法确定感受时按 capture-rules §6 的默认规则处理；不要自行扩展情绪关键词表。

## 示例

用户：`刚完成文章初稿，下一步准备开会`

助手：`⏱️ 14:32 | 间隙记录已保存；下一步：准备开会`

## 约束

- 时间戳使用 GMT+8；
- 记录应在 30 秒内完成，感受如实保留；
- 不把“继续工作”当作具体下一步；
- 不引用已删除的时间线 skill；需要查看合并时间线时使用 `cc-activity`。
