# Media 宿主适配契约

`media/skills/` 是 Claude Code 与 Codex 的共享业务真源。Skill 不读取宿主专属变量，也不假设当前目录是某个插件缓存目录。

## 资源定位

- 运行时优先使用当前宿主提供的插件根路径；在本地开发时可显式设置 `MEDIA_PLUGIN_ROOT`。
- 共享脚本从当前 Skill 的相邻 `scripts/` 目录解析；不要写死 `${CLAUDE_PLUGIN_ROOT}`、Codex 缓存路径或用户私有绝对路径。
- Claude 的 `/media:*` 命令只负责透传参数；Codex 使用对应 `$media:*` Skill。两者都把结果写回当前任务，不自动发布外部内容。

## 能力映射

| 能力 | Claude Code | Codex |
|---|---|---|
| 交互提问 | 当前宿主的提问能力 | 当前任务中的结构化提问或直接选项 |
| 联网检索 | 当前宿主可用的联网检索 | 当前宿主可用的联网检索 |
| 文件读写 | 当前宿主文件工具 | 当前任务可用的文件工具 |
| 入口 | `/media:<skill>` | `$media:<skill>` |

共享 Skill 不引用这些入口来驱动下一步，只描述下一步的 Skill 名称，避免把一个宿主的命令语法泄露给另一个宿主。
